# TrustCV demo sample files

These are synthetic, locally generated demo fixtures. They are not sourced from external datasets and contain no personal information. Recreate them from the project root with:

```powershell
.\.venv\Scripts\python.exe scripts\create_demo_assets.py
```

See the root [DEMO_GUIDE.md](../DEMO_GUIDE.md) for the timed walkthrough, expected scan counts, source/purpose notes, and hash-verification limitations. In particular, the `.bin` fixture is plain synthetic data for hashing only, not a valid model.
